# maths

Short papers and research notes in mathematics by
[Justo Tapiador](https://github.com/Justo-Tapiador) (Universidad de Alicante).

Each paper lives in its own folder together with its LaTeX source, figures,
verification code and data, so that every numerical claim in the text can be
checked and reproduced independently.

## How to cite

Each paper provides a BibTeX entry in its folder's README — cite the paper
you use from there. The root `CITATION.cff` (which powers GitHub's
"Cite this repository" button) cites paper #1, *The Prime Staircase*, as
the repository's founding paper; per-paper citations should always be taken
from the corresponding folder.
